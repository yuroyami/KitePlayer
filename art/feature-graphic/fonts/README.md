# Fonts

The feature graphic uses two fonts, both under the SIL Open Font License 1.1.
The files are the latin subsets that Google Fonts serves, so the page renders the same on every machine.

| File | Font | License |
| --- | --- | --- |
| `outfit-latin.woff2` | [Outfit](https://github.com/Outfitio/Outfit-Fonts), variable weight 100 to 900 | `OFL-Outfit.txt` |
| `jetbrains-mono-latin.woff2` | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), variable weight 100 to 800 | `OFL-JetBrainsMono.txt` |
